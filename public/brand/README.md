# Brand files to replace (keep the same file names)

| File | Spec |
|---|---|
| logo.svg | Light-mode logo, SVG, about 140x36 viewBox, transparent background |
| logo-dark.svg | Dark-mode logo (light-colored artwork), same size |
| favicon.svg | Square SVG, can use prefers-color-scheme inside |
| favicon.ico | 32x32 (or multi-size) ICO |
| apple-touch-icon.png | 180x180 PNG, opaque background |
| icon-192.png / icon-512.png | PNG, used by site.webmanifest |

Logo sizing is set by `.logo img` in css/app.css (36px tall).
