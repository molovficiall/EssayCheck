# Self-hosted fonts

The storefront self-hosts:

- `Archivo-Variable.woff2` (weight and width axes)
- `IBMPlexSans-Variable.woff2`
- `IBMPlexMono-Regular.woff2`
- `IBMPlexMono-SemiBold.woff2`

The corresponding SIL Open Font License notices are included as `OFL-Archivo.txt`, `OFL-IBM-Plex-Sans.txt`, and `OFL-IBM-Plex-Mono.txt`. These assets are local; no font CDN is used.
