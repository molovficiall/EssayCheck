# Favicon assets

The generated neutral placeholder set is in this directory. Replace `favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, and `maskable-icon-512.png` with branded versions and preserve their dimensions (32×32, scalable, 180×180, 192×192, 512×512, and 512×512 respectively). Keep `site.webmanifest` names and icon paths in sync.
