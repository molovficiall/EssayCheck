# Replaceable brand assets

Replace `logo-placeholder.svg` and `logo-placeholder-dark.svg` with monochrome logo variants while preserving the 160×40 viewBox, then update the shared header/footer/admin component only if you change the dimensions. Replace the six files listed in `favicon/README.md` with the supplied brand marks. The app self-hosts licensed Archivo, IBM Plex Sans, and IBM Plex Mono WOFF2 files in `../fonts/`; see their license notices and font README.
